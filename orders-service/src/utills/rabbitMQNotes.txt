# ❌ WAY 1: WITHOUT Exchange & Binding (BAD PRACTICE)

👉 Producer sends messages **directly to queues**

### 🧱 Problem with this approach

* Producer must know **all queues**
* Tight coupling
* Adding new service = change producer code ❌

## 🔴 Producer (BAD – direct to queues)

```js
const amqp = require("amqplib");

async function producer() {
  const conn = await amqp.connect("amqp://localhost");
  const ch = await conn.createChannel();

  // Queues
  await ch.assertQueue("email_queue");
  await ch.assertQueue("sms_queue");
  await ch.assertQueue("refund_queue");

  // order.created → email
  ch.sendToQueue("email_queue", Buffer.from("Order Created"));

  // order.shipped → sms
  ch.sendToQueue("sms_queue", Buffer.from("Order Shipped"));

  // order.cancelled → refund
  ch.sendToQueue("refund_queue", Buffer.from("Order Cancelled"));

  console.log("❌ Messages sent directly to queues");

  setTimeout(() => conn.close(), 500);
}

producer();
```

## 🔴 Why this is BAD (remember this)

❌ Producer knows all consumers
❌ Hard to scale
❌ No routing logic
❌ NOT industry standard

> **Interview answer:** “This tightly couples the producer with consumers.”

# ✅ WAY 2: WITH Exchange & Binding (CORRECT / INDUSTRY)

👉 Producer sends **events**, RabbitMQ decides routing.

---

## 🧠 New thinking (VERY IMPORTANT)

Producer says:

> “Order created”

Producer does **NOT say**:

> “Send email, send SMS, refund”

RabbitMQ handles that.

## 🟢 Producer (GOOD – uses exchange)

```js
const amqp = require("amqplib");

async function producer() {
  const conn = await amqp.connect("amqp://localhost");
  const ch = await conn.createChannel();

  const exchange = "order_exchange";

  await ch.assertExchange(exchange, "direct");

  // Send events
  ch.publish(exchange, "order.created", Buffer.from("Order Created"));
  ch.publish(exchange, "order.shipped", Buffer.from("Order Shipped"));
  ch.publish(exchange, "order.cancelled", Buffer.from("Order Cancelled"));

  console.log("✅ Order events published");

  setTimeout(() => conn.close(), 500);
}

producer();
```

---

## 🟢 Email Consumer

```js
const amqp = require("amqplib");

async function emailConsumer() {
  const conn = await amqp.connect("amqp://localhost");
  const ch = await conn.createChannel();

  await ch.assertExchange("order_exchange", "direct");
  await ch.assertQueue("email_queue");

  // order.created → email_queue
  await ch.bindQueue("email_queue", "order_exchange", "order.created");

  ch.consume("email_queue", msg => {
    console.log("📧 EMAIL:", msg.content.toString());
    ch.ack(msg);
  });
}

emailConsumer();
```
