Kernel : Kernel is the core part of the OS that manages hardware, threads, memory, file system, and all low-level operations. Node.js relies on the kernel — via libuv — to perform non-blocking I/O using background threads.
what is libuv : 
libuv = A C library inside Node.js
 It handles:
✔ Event loop
 ✔ Thread pool
 ✔ Non-blocking I/O
 ✔ Timers
 ✔ Async operations
But libuv itself cannot read files, open sockets, or write to disk directly.
Because only the Operating System Kernel is allowed to do those low-level tasks.
Kernel : 
The kernel is the one that actually talks to:
File system
Network
CPU
Disk
Threads
System resources
libuv only requests the kernel to perform these tasks.
Libuv and kernel relation : 
libuv sends I/O work to the OS kernel, and the kernel executes it using its internal threads, drivers, and system calls.
