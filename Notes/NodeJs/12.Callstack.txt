Callstack : 
=========
→ JavaScript is a synchronous, single-threaded language, so it can execute only one task at a time.
→ The *call stack* is a data structure inside the JavaScript engine where functions are executed.
→ When a JavaScript program starts, the Global Execution Context (GEC) is created and pushed into the call stack.
→ Whenever a function is called, a new execution context is created and pushed to the top of the stack.
→ After the function finishes, its execution context is popped out.
→ JavaScript always executes code from the top of the call stack.”
