What is Closures : 
===================
A function along with reference to a outer environment like together forms a closure so in other words we can say that closure is a combination of a function and it's lexical scope bundle together forms a closure 
–can you explain more about it 
Each and every function in javascript has access to its outer lexical environment that means like access to variable, functions which is present in environment of its parent 

→ point -2 : even when this function is executed in some other scope not in an original scope it still remembers its outer lexical environment where it was originally present in the code so that is what closure is.

Even when a function is executed outside of its original scope, it still remembers and can access the variables from the scope where it was created. This “remembering” of the lexical environment is what we call a closure.

EX: it's for especially point :2
function outer() {
  let count = 0; // outer lexical environment

  function inner() {
    count++; // inner remembers `count` from outer
    console.log("Count is:", count);
  }

  return inner; // return inner function
}

const fn = outer(); // outer() runs and returns inner
fn(); // Count is: 1
fn(); // Count is: 2
fn(); // Count is: 3


Explanation

outer() creates a variable count and defines inner().

When we return inner, and call it later (even outside of outer), it still remembers count because of closure.

That’s why every call increases the same count, not a new one.
