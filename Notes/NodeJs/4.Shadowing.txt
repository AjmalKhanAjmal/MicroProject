Shadowing : 

🔑 Definition of Shadowing
I  we have same variable out side the block 
Shadowing happens when a variable declared in an inner scope has the same name as a variable in an outer scope.
 👉 The inner variable “shadows” (hides) the outer one inside that scope.


Example with var
function test() {
  var a = "outer a";

  if (true) {
    var a = "inner a (shadowing outer)";
    console.log(a); // 👉 "inner a (shadowing outer)"
  }

  console.log(a); // 👉 "inner a (shadowing outer)" 
}
test();

Since var is function-scoped, the inner declaration overwrites the outer one.



Example with let and const
function test() {
  let b = "outer b";

  if (true) {
    let b = "inner b (shadowing outer)";
    console.log(b); // 👉 "inner b (shadowing outer)"
  }

  console.log(b); // 👉 "outer b"  (outer value not affected)
}
test();

With let and const, the shadowing happens only inside the block {}.


The outer variable remains unaffected.



❌ Illegal Shadowing
You cannot shadow a let or const variable by using var in the same scope:
function test() {
  let c = 10;
  var c = 20; // ❌ SyntaxError: Identifier 'c' has already been declared
}

But shadowing with let → let or const → let etc. inside different scopes is allowed.

✅ In short:
Shadowing = declaring the same variable name in inner scope.


var → shadows at function level.


let / const → shadows at block level.


Illegal shadowing = mixing var with let / const in the same scope.
